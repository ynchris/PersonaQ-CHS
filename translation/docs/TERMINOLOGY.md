## 使用规则

2026-09-28 素材说明补充：365—366批的讨伐来源采用暂定敌名，原日文对应可由带源哈希的datmaterialhelp及消息索引追溯。玛雅、阿布鲁利、玛利亚、丘比特等词根保持批内一致；宝物之手、财宝之手、至高之手分别对应不同原名，不能合并。敌名尚未回写战斗名称表，须与后续图鉴、名称表统一，不视为已核实的官方译名。材料外观、暗力染色、封住行动等描述不得自行补成必掉条件。

2026-09-10 新增开场术语：

- テオドア → 迪奥多；テオ → 迪奥（称呼保留简称）。参考 [Theodore 的其他语言名称](https://megamitensei.fandom.com/wiki/Theodore)，繁体名称为「迪奧多」，本项目采用简体写法。
- レギオン → 恶灵军团。参考 [Legion 的中文名称](https://megatenwiki.com/wiki/Legion)。开场关于名字词义的解释译为「它的名字 Legion，意为军团」，保留原段落的解释关系。
- ベルベットルーム → 天鹅绒房间；タルタロス → 塔尔塔罗斯。沿用当前开场与角色介绍草稿，纳入后续术语复核。
- 2026-09-10 学校受困段落草稿：シャドウ → 阴影；八十神高校 → 八十神高中；チドリン → 小千鸟（顺平对千鸟的昵称）。上述草稿称呼纳入全篇统一审校，不视为新增外部来源核实。
- 2026-09-10 DLC 导航草稿：パワースポット → 能量点（与技能/菜单已有草稿一致）；刈り取る者 → 猎杀者；クマ → 小熊；コロ → 小虎（虎狼丸的简称）；様按迪奥多说话风格暂译“大人”。这些称呼仍需全篇术语与语气审校，不是新增来源核实。
- 五人导航补全批次：伊丽莎白保留郑重语气和冷幽默；玛格丽特保持礼貌语气，さん不逐处硬译为“先生/小姐”；玛丽保留简短、直白的语气；菜菜子保留“哥哥/姐姐”及自称。P4 名称草稿统一为花村阳介、里中千枝、天城雪子、巽完二、白钟直斗、小熊、菜菜子，仍纳入最终术语复核。オルギアモード沿用已有“狂欢模式”，オーバーヒート沿用“过热”。

- 使用简体中文，同一个实体在剧情、菜单、图鉴与 DLC 中采用一致译名。
- 角色称呼按语境保留姓氏、名字、昵称与敬称差别，不对整段文本做机械替换。
- 恶魔/人格面具先按日文原名核实实体，再确定中文译名；分类页仅用于定位具体条目。
- 技能译名参考 P3R 时，核对日文名、属性和效果；伤害、消耗、范围等数值与机制始终以 PQ 原始数据为准。
- 存在多个译名或跨作品机制差异时记录待核对项，不冒充已确认翻译。
- 新增术语必须进入最终字库覆盖检查；保留文本控制码和动态姓名变量。

## 2026-09-10 主线新增术语与语言改写

- オルフェウス → 俄耳甫斯；ワイルド → 不羁。参考 [P3 主人公中文条目](https://zh.wikipedia.org/wiki/主角_(女神异闻录3))。メサイア → 弥赛亚，另见 [Messiah 多语言名称](https://www.megatenwiki.com/wiki/Messiah)。这些网页用于名词核对，剧情正文始终翻译自本地日版游戏。
- 不思議の国のアナタ → 不可思议之国的你；てづくりこ～ぼ～/手作り工房 → 手工工坊；白紙のカード → 空白卡片；編成 → 编队。本轮草稿统一译法，后续需与菜单/地图贴图一并统一。
- フューシス・オイケイン・エイドロン → 菲西斯·奥伊凯因·艾多隆（草稿音译），简称仍为 F.O.E。保留两次重复长名称及顺平听不懂的反应，不直接换成解释性译名破坏笑点。对照 [PQ 日文用语集](https://wikiwiki.jp/personaq/用語集)；该词与 Q2 的长名称不同，不能复用 Q2 全称。
- シンジ → 阿真，アキ → 阿明，ゆかちゃん → 小由加，アイちゃん → 小埃，为本轮角色间昵称草稿，待统一语气审校。草莓拆词和“モテる/持てる”误听采用中文双关改写，详情见 WORKLOG，本轮不声称已经定稿。
